# LightOps TUI

Terminal UI for LightOps Cloud Agent.

Start Cloud Agent first:

```bash
node apps/cloud-agent/src/server.mjs
```

Then run:

```bash
node apps/cloud-agent-tui/src/main.mjs
```

Or use the launcher:

```bash
bin/lightops
```

Windows PowerShell:

```powershell
.\bin\lightops.ps1
```

Commands:

- `/scan`
- `/incident create`
- `/fix`
- `/deploy`
- `/rollback`
- `/audit`
- `/config`
- `/quit`
